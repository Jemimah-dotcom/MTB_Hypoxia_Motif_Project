# MTB_Hypoxia_Motif_Project
Motif discovery in hypoxia-induced genes of Mycobacterium tuberculosis using MEME
This repository contains motif discovery analysis for hypoxia-induced genes of Mycobacterium tuberculosis usuing MEME. It includes using motif logos of upstream regions of varying lengths.
